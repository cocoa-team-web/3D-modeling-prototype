3D Modeling Web — прототип v1

Запуск:
1. Распакуйте архив.
2. Откройте папку проекта в редакторе кода.
3. Запустите локальный веб-сервер (например: python -m http.server 8000).
4. Откройте http://localhost:8000 в современном браузере.

Важно:
- Для Three.js используется CDN, поэтому при запуске нужен интернет.
- Это независимый браузерный прототип, а не автоматически конвертированный Unity APK.
- В APK найдены Unity Addressables с preset-моделями, сценой, панелями инструментов моделирования, скульптинга, материалов, UV и экспорта. Чтобы приблизить интерфейс и функции к оригиналу, следующим этапом нужно детально изучить эти ресурсы и сверить приложение со скриншотами/видео.
- Используйте извлечённые из APK материалы только если у вас есть право на их использование.
